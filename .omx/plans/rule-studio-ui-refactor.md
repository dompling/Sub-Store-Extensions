# 规则集配置与订阅体检收敛计划

## 行为保护

- 保留规则集项目的创建、编辑、归档、恢复、预览、刷新和资源提供能力。
- 保留规则库目录的缓存、过期回退和强制刷新行为。
- 为存储 schema 迁移、规则库启停过滤和 API 契约补充回归测试后再改实现。
- 订阅体检保留现有分析数据和脱敏历史，只调整信息优先级与呈现，不伪造网络可达性、延迟或解锁检测。

## UI 收敛

- 删除规则集列表页自建常驻搜索/刷新/归档工具条，复用配置生成器的列表容器、卡片、展开操作、空状态和单/双列模式。
- 使用 Host 导航栏的设置入口管理规则库；列表页只展示项目。
- 编辑页复用配置生成器的表单区块、来源摘要卡片、底部弹层编辑和 40/60 底部操作栏。
- 编辑页的规则库选择器只消费已启用规则库；没有启用项时提供明确的“去配置规则库”入口。
- 将订阅体检首屏改为阻断、需处理、可忽略三类行动结论，纯统计降为次级信息。

## 边界与简化

- 不新增依赖，不修改 Host 私有存储，不让插件彼此读取安装目录或私有路由。
- 规则库设置存储在 `rule-studio` 独立 key 中，并提供 schema 1 到 schema 2 的无损迁移。
- 优先删除重复 CSS 和自建交互，复用 NutUI、Host 页面动作及现有主题变量。
- Rule Studio 与 Subscription Doctor 独立升级版本，不强制对齐。

## 验证

- 插件单元/契约/后端 bundle 测试。
- TypeScript 类型检查、前后端构建、打包、repository 与 verify。
- 本地安装后，在 8888 对照配置生成器进行桌面和窄屏截图验收，视觉分数目标 90+。
