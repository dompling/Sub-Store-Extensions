# Rule Studio 表单 UI 收敛计划

## 目标

将规则集配置、来源编辑、规则库管理、规则库选择及预览格式选择统一到宿主和配置生成器现有的表单视觉语言，同时保持现有数据结构、业务行为和路由不变。

## 行为基线

- 新建规则集时“基本信息”和“来源”默认展开；编辑已有规则集时所有折叠区默认收起。
- 来源仍支持远程 URL 与粘贴/文件两种类型。
- 规则库选择仍只读取已启用规则库，最多添加 20 个有效来源，且已添加 URL 不可重复选择。
- 规则格式、分类/首字母和预览输出格式仍使用弹窗选择，不引入原生 `select`。
- 规则库新增、编辑、启停、刷新、删除行为不变。

## 修改顺序

1. 新增一个 Rule Studio 内部复用的单选弹窗组件，替换三个页面各自的 NutPicker 接线和宿主层级补丁。
2. 对齐主编辑页的 NutUI 表单标签、字段主体、开关、卡片边框和固定底部操作区。
3. 对齐来源编辑与规则库编辑弹窗的标题层级、字段布局、内容滚动和底部操作区。
4. 收敛规则库列表页：移除非空状态下的重复新增入口，强化卡片与操作区层级。
5. 收敛规则库选择页：标题栏和底部操作限制在 900px 内容宽度，统一搜索、筛选与选择卡片。
6. 更新静态 UI 契约测试，运行 typecheck、测试、构建和真实浏览器回归。

## 不做事项

- 不修改后端 API、缓存逻辑、解析器或规则格式转换。
- 不新增依赖。
- 不重构其他插件或宿主公共组件。
- 不覆盖工作区中现有的配置生成器、仓库包或发布文件改动。

## 第四轮：取消折叠并将规则集选择改为弹窗

### 行为基线

- 名称、描述、精确去重、保留注释的数据模型和保存字段保持不变。
- 来源添加、编辑、拖拽、删除及规则库批量添加行为保持不变。
- 规则库搜索、分类、刷新、分批加载、已添加禁选和最多二十个来源的限制保持不变。

### 修改顺序

1. 删除编辑页的三组折叠标题、展开状态和摘要计算，把基础字段与规范化开关合并成一个连续表单。
2. 将来源面板直接放在连续表单之后，不新增替代分类标题。
3. 将 SourceCatalogPicker 的 fixed 全屏页改成 NutPopup，弹窗内部保留标题、搜索、筛选、列表和底部操作区。
4. 桌面端弹窗宽度限制为 900px、高度限制为视口约 82%；移动端保持底部 Sheet 和独立滚动。
5. 更新静态 UI 契约，重新打包安装并用真实 Chrome 验证。
